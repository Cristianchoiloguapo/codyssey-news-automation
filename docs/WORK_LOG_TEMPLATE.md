# Project B | 팀 프로젝트 수행 기록

## 1. 프로젝트 개요

**프로젝트명:** AI 뉴스 요약 자동화 워크플로우

**프로젝트 목표:** AI 관련 최신 뉴스를 RSS로 수집하고, 생성형 AI를 통해 핵심 내용을 한국어 3줄 이내로 요약한 뒤 Notion 데이터베이스에 자동 저장하는 시스템 구축

## 4. 개발 과정 및 주요 시행착오

### ① RSS 뉴스 수집

- TechCrunch의 AI 관련 RSS 피드를 활용하였다.
- Python의 `feedparser`를 사용하여 뉴스를 수집하였다.
- 최초 테스트에서 AI 관련 기사 14건을 필터링하고 기사 본문 추출을 확인하였다.

### ② AI API 인증 오류

**문제:** 최초 API 호출에서 `401 Unauthorized` 발생

**원인:** 코디세이에서 제공한 API 키를 일반 OpenAI API 서버로 요청하였다.

**해결:** 코디세이의 전용 API 주소 `https://copa.codyssey.kr/v1`을 사용하고 Chat Completions 방식으로 변경하였다.

### ③ GitHub 계정 인증 오류

**문제:** `git push` 실행 시 `Repository not found` 발생

**원인:** Git에 저장된 인증 계정과 프로젝트 저장소 소유 계정이 서로 달랐다.

**해결:** Git Credential Manager를 통해 저장소 소유 계정으로 재인증한 후 프로젝트 업로드에 성공하였다.

### ④ GitHub Actions 모델 호출 오류

**문제:** 최초 GitHub Actions 실행에서 `HTTP 404` 발생

**원인:** 자동 실행 설정에 기존 모델명인 `gpt-4.1-mini`가 남아 있었다.

**해결:** `OPENAI_MODEL`을 `gpt-5-mini`로 변경하고 코디세이 API 주소를 설정하여 정상 실행하였다.

### ⑤ 뉴스 요약문 개선

**문제:** 요약문은 세 문장으로 생성되었지만 문장이 길어 가독성이 떨어졌다.

**개선:** 각 문장을 공백 포함 65자 이내로 작성하도록 프롬프트를 수정하였다.

**추가 확인:** 수정한 프롬프트의 GitHub 반영 및 재실행 결과 확인 예정

## 5. 예외 처리 및 자동화 정책

| 상황 | 처리 방식 |
|---|---|
| RSS 수집 실패 | 오류를 기록하고 실행 결과 확인 |
| 주제에 맞는 뉴스가 없음 | 저장하지 않고 종료 |
| 중복 뉴스 발견 | 원문 URL을 기준으로 중복 여부 검사 |
| AI API 일시 오류 | 최초 요청 이후 최대 2회 재시도 |
| API 인증·모델 설정 오류 | 불필요한 반복 요청을 방지하고 실행 중단 |
| Notion 저장 오류 | 오류 로그를 남겨 원인 확인 |
| 정상 실행 | 조건에 맞는 뉴스 1건을 Notion에 저장 |

해당 정책은 자동화 시스템의 안정성을 확보하고 불필요한 API 호출을 줄이기 위해 설계하였다. 각 예외 상황에 대한 별도 테스트 결과는 최종 확인 후 보완한다.
